## 4. Trademark screen — India, classes 9 / 42 (+ 36)

- **Web-wide exact-match search:** the only result for "INOVIXUX" anywhere is
  our own repo ([github.com/pareshpatil8/INOVIXUX-Brand](https://github.com/pareshpatil8/INOVIXUX-Brand)).
  No company, product, or trademark listing found. Sources checked via web
  search: [Trademarkia](https://www.trademarkia.com/search/trademarks?q=ICONIX*&page=1&showFilters=true)
  surfaced only non-matching similar strings (INFINIOX — dead/abandoned US
  mark), plus unrelated entities (Inovio Pharmaceuticals, Infinix Mobile).
- **Adjacent mark to disclose to the attorney:**
  [**Inovix** — inovix.in](https://inovix.in/), an Indian web-design/ecommerce
  *branding agency*. Phonetically close (INO-VIX vs INO-VIX-UX) and
  India-based. Its services sit nearest class 42; our class 9/42 filing for
  DPI/fintech/healthcare infrastructure is a different trade channel, but this
  is exactly the kind of citation an examiner may raise — get an attorney view.
- **IP India registry (ipindia.gov.in) was NOT queried directly** — the public
  search portal is not reliably scriptable. A formal registry search in classes
  9 and 42 must be run by the filing attorney; this doc does not substitute
  for it.
- **Class recommendation:** file **9** (software) and **42** (SaaS/software
  services) as scoped by the issue, and ask the attorney about **class 36** —
  the product roadmap (payments, UPI, KYB underwriting, core banking) is
  squarely financial services, and class 36 is the classic gap fintech brands
  discover late.
