Button — variants, sizes, states

Five variants share one shape contract. danger (added INO-156) is the destructive register for KYB actions like reject/revoke — same filled shape as primary, a different consequence, never a fourth visual language to learn. Each pane below is the same markup under a different data-theme.

Variants × theme

dark — :root (default)

light — [data-theme="light"]

high-contrast — [data-theme="high-contrast"]

Size API — sm / default / lg

States — default, hover, pressed, focus-visible, disabled, loading
