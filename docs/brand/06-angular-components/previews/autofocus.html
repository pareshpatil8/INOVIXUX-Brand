Autofocus

A behaviour-only primitive: it paints nothing. It moves keyboard focus to a target element once, on activation — the way native autofocus does for a document's initial load, but reliable for content Angular inserts well after that moment.

Initial focus

The field below receives focus as soon as this card loads.

Route-change re-focus

Tab away from the field below, then click "Simulate navigation" — focus returns to it, standing in for a SPA route transition re-running the directive's inoAutofocusTrigger.

The shipped directive additionally resolves an explicit inoAutofocusTarget selector, defers unconditionally to an ancestor [inoFocusTrap], and forwards preventScroll to the native focus() call. See SPEC.md §3 for the full contract — this card is a vanilla-JS stand-in for the directive's one-time focus move and its route-change re-run, not a second implementation to keep in sync.
