RTL

Offsets are logical throughout — scrollLeft is normalised on read and de-normalised on write, so an Arabic or Hebrew locale scrolls the right way with no second code path. This markup uses only logical CSS properties (inset-inline-start, border-inline-end, …), never left/right.

Motion — loading shimmer

The shimmer animation is scoped to prefers-reduced-motion: no-preference; under reduce it inherits the flat bar above — the loading state stays fully perceivable, it simply stops moving. Toggle your OS "reduce motion" setting to see both branches of this preview.
