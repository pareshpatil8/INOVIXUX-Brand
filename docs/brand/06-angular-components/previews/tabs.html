Tabs — Tier 1 Panel group

A WAI-ARIA APG tablist with automatic activation: arrow keys move focus and selection together, Enter/Space still activate, and Delete closes a closable tab. The strip is derived from the projected <ino-tab-panel> children, so the aria-controls ↔ aria-labelledby pair is generated rather than hand-wired. This page is static markup mirroring the component's stylesheet — it demonstrates the painted states, not the keyboard model.

Size — control-size scale

sm / default / lg read --ino-control-height, --ino-control-padding-inline-roomy, --ino-control-font-size, --ino-control-gap and --ino-control-icon-size. Nothing is invented locally, so a [data-density="dense"] ancestor rescales all three with no component branch.

Scrollable — overflowing strip

The ‹ / › buttons appear only when the track actually overflows (a ResizeObserver in the component). The non-scrollable default wraps instead, so a caller who did not opt in never silently loses a tab off-screen.

Closable

The ✕ is presentational (aria-hidden) — a control nested inside the tab <button> would be invalid HTML and unreachable by keyboard. The keyboard path is the APG Delete key, announced through a visually-hidden suffix in the tab's accessible name. The hit box is floored at --ino-target-min (SC 2.5.8).

Disabled, invalid, loading

Invalid pairs colour with a dot so validity is never colour-only (SC 1.4.1), and uses --ino-color-danger-text-safe — the text-safe red, not the fill red. Loading keeps the label in the DOM and sets aria-busy on both the tab and its panel.

Readonly

Focusable but inert — arrow keys still move focus, activation and close are refused, hover no longer promises a selection, and non-active tabs carry aria-disabled. This is the audit-trail case: show which step was selected without letting the current viewer change it.

RTL

The stylesheet is logical-property-only, so the box layout mirrors for free. Three things need explicit handling in the component because logical CSS cannot reach them: the arrow-key direction, the sign of scrollBy() (whose left option is physical), and the ‹ / › glyphs — mirrored below with :dir(rtl) { transform: scaleX(-1) }.
