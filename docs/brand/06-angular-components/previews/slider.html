ino-slider

Single-value or dual-thumb range slider. range switches value from number to [number, number] (banana-in-a-box valueChange). Pointer drag via setPointerCapture on the thumb, click-to-jump on the track; horizontal (default) or vertical; optional step marks, value tooltip, min/max and value labels. Track size is a local two-rung sm | md scale, not InoControlSize — see SPEC.md §7. Full contract, keyboard map, and deliberate omissions: SPEC.md and slider.md.
