Layout is a plain flex row with no flex-direction override, so it mirrors automatically against the inline axis. The nav-icon glyphs are a recorded, deliberate exception — see SPEC.md §6 — flipped explicitly since chirality can't be expressed with logical properties.

Motion

Background/color/border transitions use --ino-motion-duration-fast + --ino-motion-easing-standard, the same "quick, no drama" pairing ino-button uses for non-primary state changes. Every transition on the host collapses under prefers-reduced-motion: reduce — toggle your OS setting to see both branches.
