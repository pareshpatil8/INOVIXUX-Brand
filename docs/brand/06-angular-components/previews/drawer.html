Drawer — edge-anchored overlay panel

Four logical positions (start/end/top/bottom), three sizes, modal or non-modal mode, and an automatic full-screen layout under the mobile breakpoint. Static markup below — the shipped component (ino-drawer.component.*) drives the same classes from [open]/position/size/ modal instead of a static class attribute.

Four positions (static, always "open" for preview purposes)

start

Filters, navigation — content the user reaches from the leading edge.

end

Record detail, edit forms — the default position.

top

Notifications, quick search.

bottom

Action sheets — mirrors the mobile bottom-sheet idiom on web.

Non-modal (no scrim)

Persistent panel alongside page content — modal="false" drops the scrim, the focus trap, and the body-scroll lock.

Filters

The rest of the page stays interactive while this is open.
