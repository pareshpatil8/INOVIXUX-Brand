ConfirmPopup

Inline confirm/cancel prompt anchored next to a trigger element — no scrim, no centered panel. Click a trigger below; the popup positions itself relative to the button and flips to the opposite side if it doesn't fit, the same rule overlay-position.ts's computeOverlayPlacement implements for the real component.

Escape, the Cancel button, or a click outside the popup all dismiss it — same three routes the shipped component wires up. This preview reimplements only the placement math in ~20 lines of vanilla JS for demonstration; the shipped directive additionally handles focus trapping ([inoFocusTrap]), viewport-resize/scroll repositioning, and the next-macrotask outside-pointerdown guard described in SPEC.md.
