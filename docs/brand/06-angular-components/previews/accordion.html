Accordion — vertically stacked collapsible panels

Two-component architecture: <ino-accordion> (container) + <ino-accordion-tab> (individual panel). Follows the WAI-ARIA APG accordion pattern: heading+button structure, Arrow key navigation, roving tabindex. Single-expand (default, radio-like mutual exclusion) vs multiple-expand modes. Two-value sizing scale (compact/comfortable) per the spec row.
