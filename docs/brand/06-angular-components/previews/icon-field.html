Icon field — icon-slot wrapper

The sanctioned leading/trailing icon mechanism for Tier-1 form controls — a wrapper around a projected control, not an @Input() icon re-implemented per control. Layout is side-by-side (icon outside the control's own box), not PrimeNG's icon-overlaps-input pattern — see SPEC.md §1 for why.

Variants × theme

dark — :root (default)

light — [data-theme="light"]

high-contrast — [data-theme="high-contrast"]

Size (control-size scale)

States — focus & disabled

Focus-visible on the projected control itself is unaffected by the wrapper — the ring is native to the control, never clipped (SPEC.md §7).

RTL

The leading icon (first in template order) mirrors to the trailing visual edge under dir="rtl" for free — flex-direction: row is an inline-axis direction, not a physical one.
