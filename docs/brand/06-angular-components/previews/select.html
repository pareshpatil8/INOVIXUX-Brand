Select — custom listbox

Single-selection combobox rewrite of the native <select>: filter/search, option groups, custom option/selected-value templates, clearable, editable, loading, and virtual scrolling for long lists (reuses <ino-virtual-scroller>, T-3). Full role="combobox" + role="listbox" ARIA contract with aria-activedescendant — see SPEC.md and select.md for the full keyboard map and the MultiSelect/AutoComplete/Listbox scoping decision.
