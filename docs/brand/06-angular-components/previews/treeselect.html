TreeSelect — combobox opening a role="tree" panel

Single, multiple, or cascading-checkbox selection over a hierarchical nodes tree. Lazy children, an in-panel filter that searches the whole loaded tree, and Arrow-key tree navigation (aria-activedescendant, same model ino-select uses). See SPEC.md.
