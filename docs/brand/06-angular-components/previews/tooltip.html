Tooltip

Advisory hint anchored to a trigger element on hover or focus — try hovering a button below, or tabbing to it. It positions itself relative to the trigger and flips to the opposite side if it doesn't fit, the same rule overlay-position.ts's computeOverlayPlacement implements for the real directive.

Hover or focus a trigger

Escape dismisses without moving focus; moving the pointer onto the tooltip itself keeps it open (the "hoverable" leg of WCAG SC 1.4.13). This preview reimplements only the placement math and delay timers in a few lines of vanilla JS for demonstration; the shipped directive additionally manages aria-describedby wiring and a document-level Escape guard, described in SPEC.md.
