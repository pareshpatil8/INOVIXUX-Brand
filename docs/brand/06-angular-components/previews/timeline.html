Motion

The connector between two markers draws in on first render (a scale transform from the marker outward) using --ino-motion-duration-slow + --ino-motion-easing-decelerate. The loading skeleton uses the same shimmer idiom as virtual-scroller.html. Both collapse under prefers-reduced-motion: reduce — toggle your OS setting to see both branches; this static preview does not replay the animation itself.
