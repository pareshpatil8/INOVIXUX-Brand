CascadeSelect — nested option drill-down combobox

A combobox trigger that opens a panel showing exactly one level of a hierarchical options tree at a time, with a breadcrumb trail of the path drilled into so far. Only leaf options are selectable values; parent options are drill targets. See SPEC.md.
