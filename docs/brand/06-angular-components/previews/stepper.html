Stepper — Tier 1 Panel group

A wizard-style step rail, reusing <ino-tabs>'s tablist/tab/tabpanel interaction model (the APG defines no "stepper" pattern) and adding a numbered/checkmark indicator, a connector line, orientation, and linear gating — a step unlocks only once every step before it is marked completed. This page is static markup mirroring the component's stylesheet — it demonstrates the painted states, not the keyboard model.

Size — control-size scale

sm / default / lg read --ino-control-icon-size (indicator diameter, floored at --ino-target-min), --ino-control-padding-inline-roomy, --ino-control-font-size and --ino-control-gap. Nothing is invented locally.

Vertical orientation + linear gating

In linear mode (the default), a step unlocks only once every step before it is completed — the aria-disabled "Review" step below cannot be activated until "Documents" is completed.

Disabled, invalid, loading

Invalid pairs colour with the indicator's outline (SC 1.4.1) and uses --ino-color-danger-text-safe. Loading keeps the label in the DOM and sets aria-busy on both the step and its panel.

Readonly

Focusable but inert — arrow keys still move focus, activation is refused, and non-active steps carry aria-disabled. This is the audit-trail case: show which step was reached without letting the current viewer change it.
