KeyFilter

A behaviour-only primitive: it paints nothing. It blocks keystrokes and pastes that don't match a preset or custom pattern, on whatever field it's attached to — never rewriting or reformatting the value, unlike <ino-inputmask>. Try typing a letter into the numeric fields below, or pasting 12a34.

int — digits, one leading minus

—

num — digits, one leading minus, one decimal point

—

alphanum — custom pattern (regex preset: [a-f0-9])

—

Rejections are logged in each read-out purely so the behaviour is visible without opening devtools — the shipped directive announces nothing to assistive technology by default (inoKeyfilterReject exists for a caller that wants its own announcement). Filtering happens only in keydown, only for a single printable character with no modifier held, and is skipped entirely while isComposing — an IME composing non-Latin text is never touched. Tab, Backspace, arrows, and every Ctrl/Cmd/Alt combo are never intercepted.
