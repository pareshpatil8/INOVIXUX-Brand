Anchored overlay for arbitrary projected content — a filter form, a menu, a preview card. Click a trigger below; the panel positions itself relative to the button and flips to the opposite side if it doesn't fit, the same rule overlay-position.ts's computeOverlayPlacement implements for the real component.

Anchored trigger, with header + close icon

Filters

Escape, the close button, or a click outside the panel all dismiss it — same three routes the shipped component wires up (closeOnEscape, showCloseIcon, dismissable). This preview reimplements only the placement math in ~20 lines of vanilla JS for demonstration; the shipped component additionally handles focus trapping ([inoFocusTrap]), viewport-resize/scroll repositioning, and the next-macrotask outside-pointerdown guard described in SPEC.md.
