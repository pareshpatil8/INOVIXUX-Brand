Card — header / footer / media slots

The generic surface container: bento-grid tiles, KYB finding cards, mobile list rows, dashboard widgets. This uplift adds a full-bleed media slot (PrimeNG Card's header template shape), a size API for the header/footer chrome, and disabled/loading states — see card.md for the full API and web/src/app/components/card/SPEC.md for the decisions behind them.
