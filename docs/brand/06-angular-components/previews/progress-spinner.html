ProgressSpinner — loading / process status indicator

A standalone loading affordance, extracted from the inline ring ino-button/ ino-tag already draw for their own loading state. Supports both indeterminate (continuous spin) and determinate (percentage ring) modes, per the PrimeNG ProgressSpinner benchmark.
