Colors — Surface

The background depth ramp: base surface, one step up (surface-raised, cards/panels), one step down (surface-sunken, inset panels/inputs/code blocks — below surface, not above), and the modal/sheet scrim. Source: tokens.css §2.

Theme × surface depth

dark — :root (default)

surface — base
surface-raised — cards, panels (+ elevation-1)
surface-sunken — inset fields, code blocks
overlay-scrim — modal/sheet backdrop only

light — [data-theme="light"]

surface — base
surface-raised — cards, panels (+ elevation-1)
surface-sunken — inset fields, code blocks
overlay-scrim — modal/sheet backdrop only

high-contrast — [data-theme="high-contrast"]

surface — base
surface-raised — border-distinguished, no shadow
surface-sunken — already at the black floor
overlay-scrim — modal/sheet backdrop only

High-contrast distinguishes surface-raised by border, not luminance, and flattens elevation shadows to none — see the shadows card.
