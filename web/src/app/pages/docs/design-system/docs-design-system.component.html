Docs / Design system

Core interactive components

Buttons, form controls, modal, and toast/alert/banner — the two component groups everything else (forms, mobile screens, KYB review flows) is built on (INO-83). Every state below is the real Angular component from web/src/app/components/, token-bound only (09-design-system-standards.md §5). Structural components — nav, hero, cards, deployment tiers — are demonstrated on the homepage instead of repeated here.

Buttons

Four variants; every state is a real interaction, not a screenshot.

Form controls

Labeled, with WCAG 2.2 label/error/focus-visible states and --ino-target-comfortable on every control.

Modal

Focus-trapped, closes on Escape or backdrop click, restores focus to the trigger button on close.
