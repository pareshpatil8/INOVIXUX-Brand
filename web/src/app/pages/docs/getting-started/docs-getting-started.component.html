Getting started

There is no external API or account to sign up for yet — KYB integration is paused per the 2026-09-07 directive. This page documents the model the system is built around, so it's legible before any live surface exists.

The model

Every module follows the same four-step anatomy:

  • Trace — raw data is pulled and logged step by step, never merged silently.
  • Structure — the trace resolves into a single risk-flag report.
  • Review — a human reads the report and the underlying trace.
  • Resolve — the reviewer closes the case; only then does anything read as "verified."

What's real today

This site (the marketing/docs surface) is real, running Angular. The KYB risk-review dashboard described throughout this documentation is a separate, paused codebase — nothing on this domain calls it.
