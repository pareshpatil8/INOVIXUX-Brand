Component library

Browse the implemented Angular components, inspect their inputs and defaults, and try their live previews. Start with the design-system foundations for typography, themes and interaction guidance.

Choose a component

  • Actions and forms: buttons, inputs, selects, checkboxes, radio groups and toggles collect decisions and data.
  • Feedback: alerts, toasts, progress bars and skeletons communicate status and loading.
  • Navigation and structure: tabs, steppers, cards and layout components organize a page or flow.

Read and integrate

Open a component below for its API, theme previews, accessibility contract and limitations. Import its standalone class into your Angular component, bind the listed inputs, and handle emitted events in your application. The native button uses button[ino-button]; most other controls use an ino-* element. Check the source selector before use.

API tables are generated from source inputs. Live previews are minimal: collection-based components may need application-supplied options, rows or columns to show useful content.
