States

Default/hover/focus-visible/active are live on every header/leaf above — tab onto one for the focus ring, or hover for the surface-sunken fill. Expanded per node is the accordion behaviour itself: each group header's aria-expanded reflects its own independent state, and collapsing a panel never clears its descendants' expand state (collapse "Payments" above after opening "Disputes", then reopen it). Disabled on a group makes its children permanently unreachable — not merely dimmed while still expandable. Readonly (whole tree) renders every leaf as inert text while groups stay togglable. Loading swaps in skeleton rows with aria-busy="true". Empty renders the emptyLabel message rather than nothing.

Labels — section labels and long-label wrapping

No required/help-text/error-text inputs apply (a panel menu has no bound value to validate — see the narrative doc's "Deliberate omissions"). Every group's own label doubles as that group's section label (no separate heading input). A long individual leaf label truncates with an ellipsis rather than forcing the row to overflow its container.

Keyboard contract

Tab moves between group header buttons and leaf links/buttons in document order — a collapsed group's descendants are not in the DOM, so they are simply absent from the tab order until expanded. Enter/Space toggle a focused group header or activate a focused leaf — native <button>/<a> behaviour, no custom keydown handling (deliberately not a role="tree" single-tab- stop widget — see the narrative doc's accessibility contract).
