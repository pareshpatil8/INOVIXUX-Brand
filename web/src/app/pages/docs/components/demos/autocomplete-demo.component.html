Variants — structure

Every box below ships real options, so [role="option"] rows are actually reachable — the generic renderer's options: [] default never populated any of these.

Variants — grouped options

Two groups (Fruits/Vegetables), each with one disabled row — confirms group headings render and the disabled row is skipped by keyboard navigation.

Variants — virtualized list

120 options, above the default virtualScrollThreshold (100) — the panel renders through <ino-virtual-scroller>, not a plain *ngFor.

Variants — multiple selection

multiple renders a chip row on the trigger. The second box reaches maxSelected — unselected rows dim rather than disable (existing chips stay removable) and a role="status" message announces the cap; its panel is forced open below to show the dimmed rows directly.

States

required, disabled, readonly, loading (with a non-empty query so the spinner and typed text are visible together), and error (a string input, not auto-demoed by the generic renderer's boolean-only state filter).

States — open panel

Forced open via the component's own public openPanel() (same path a real click/focus takes) so open, no-results, and searching are screenshot-able without a visitor having to interact first.

Sizing

size: InoControlSize is a type alias, so the generic renderer's manifest-driven sizeExamples() never populates it — sm/default/ lg set explicitly here.

Labels — hint, error, RTL

Non-empty label/hint/error — the generic renderer's defaultValueFor() returns '' for every string input, so none of these ever rendered visible text there.

Keyboard contract

Focus any box above and try: ArrowDown/ArrowUp moves the active row, skipping disabled rows; Home/End jump to the first/last enabled row; Enter selects the active row (single mode closes the panel, multiple mode stays open); Escape closes without changing the value; Tab commits (with forceSelection) and moves focus on.
