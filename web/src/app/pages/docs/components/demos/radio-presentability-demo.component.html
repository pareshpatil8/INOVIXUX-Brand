Standalone (PrimeNG RadioButton shape)

A lone <ino-radio>, usable outside any group — each gets its own auto-generated name so it never joins another radio's native group.

States

Default, checked, disabled, readonly, loading and invalid below are static per-state snapshots; hover / focus-visible / active are live on every enabled control on this page — hover or tab onto any radio above or below to see them.

Sizing

The three-rung control-size scale — sm / default / lg.

Density — dense vs. fluid

This docs page renders in the dense register by default ([data-density="dense"] on the layout host); the pane on the right overrides to the fluid row-height floor to show the contrast.

Radio group

Shared name, one validation message, value as a single string — composes N standalone <ino-radio> rows.

Group validation — invalid state

A non-empty group error renders the shared message on the <fieldset> and paints the invalid ring on every item ([invalid]="!!error", INO-366 — this per-item wiring was previously missing).

Dense-table usage

A single-select column inside a dense data table — the row's own min-height comes from the table row, not ino-radio's row wrapper, so the control never inflates row height.
