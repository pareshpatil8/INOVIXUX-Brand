Variants — India-stack presets

preset resolves the mask + placeholder character from mask-presets.ts and takes precedence over an explicit mask. Each box below is prefilled with the preset's documented example value.

Variants — explicit custom mask

mask grammar (mask-tokens.ts): 9 digit, a/A letter (A auto-uppercases), * letter-or-digit, ? marks the rest optional, \ escapes a literal. Example: a 6-digit PIN code with an optional 4-digit extension.

States

Default, disabled, readonly, invalid/error, loading, and incomplete (derived — true once any slot is filled but a required slot is still empty, shown here via a partially-typed PAN). Hover / focus-visible / active are live on every enabled box above and below — hover or tab onto one to see them.

Sizing

Labels — hint, error, wrapping, RTL

Label association via <ino-label for>; hint text; error text with role="alert" plus aria-describedby; long labels wrap; the format description and literal separators render correctly under dir="rtl" since the stylesheet uses only logical properties.

Keyboard / caret management

Focus any box above and try: typing advances the caret past literal separators to the next editable slot; Backspace/Delete clear the previous/next editable slot (or the full selection) and land the caret there; paste threads the clipboard text through the mask; focusing an empty field jumps the caret to the first empty editable slot; Arrows/Tab/Home/End use native caret movement unchanged.
