Variants — single value

Every box below sets a real min/max/value so each thumb's aria-valuemin/aria-valuemax/aria-valuenow is a real number, not NaN.

Variants — vertical orientation

Variants — range (dual thumb)

range="true" switches value from a plain number to a [number, number] tuple. The lower thumb is clamped to never exceed the upper thumb and vice versa.

States

Default, disabled, readonly, required, invalid/error (string input — not auto-demoed by the generic renderer), and at-min/at-max (the thumb sits flush against a track boundary). Hover and focus-visible are live on every enabled box — tab onto one to see the focus ring.

Sizing

Track thickness — the documented 2-rung scale, sm / md. A slider's varying dimension is track thickness, not control height, so this is a narrower local scale rather than the fleet-wide sm | default | lg control-size union.

Density — dense vs. fluid

This docs page renders in the dense register by default ([data-density="dense"] on the layout host); the pane on the right overrides to the fluid row-height floor to show the contrast — the thumb diameter tracks --ino-control-icon-size-default (16px dense / 20px fluid), orthogonal to the trackSize sm/md scale above.

Labels — hint, error, wrapping, RTL

Label association via <ino-label for>; hint text; error text with role="alert"; long labels wrap; the track, fill, and thumb positioning use only logical properties (inset-inline-*/inset-block-*) so they mirror correctly under dir="rtl".

Keyboard contract

Focus any thumb above and try: ArrowRight/ArrowUp increments by step; ArrowLeft/ArrowDown decrements by step; PageUp/PageDown moves by step * 10; Home/End jump to min/max; Tab moves to the other thumb in range mode, or the next control.
