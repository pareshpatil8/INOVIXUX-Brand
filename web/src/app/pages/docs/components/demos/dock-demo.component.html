Position — bottom (row) vs. side (column)

position="bottom" lays items out as a horizontal row with the hover label above the icon; position="side" lays them out as a vertical column with the hover label to the inline-end (the component assumes a left-anchored dock by default — see SPEC.md §2). The component never fixes itself to the viewport; the consumer anchors it.

Sizing — icon sm / md / lg

sm 36px, md 44px (default), lg 52px buttons with 16/20/24px icons. Sizes are fixed px geometry (SPEC.md §3), so the dense/fluid density register below leaves the dock unchanged — unlike a form control, a dock is floating chrome and must not shrink in the dense register.

Magnify-on-hover

Hover (or keyboard-focus) any icon below to see the CSS-only magnify effect (transform: scale(1.22)). It is fully disabled — not just un-animated — under prefers-reduced-motion: reduce, and can also be turned off explicitly with [magnify]="false" (right pane) independent of the OS motion setting.
