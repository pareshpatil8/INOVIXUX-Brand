Structure — 4-column grid

Each item renders an icon, title and description; the grid reflows to 2 columns on tablet and 1 column on mobile (viewport behaviour, not a component @Input).

Structure — partial row (2 items)

The grid does not force a minimum item count or pad short rows with placeholders.

States — empty

No empty-state message is rendered by the component itself — an empty items array renders nothing. Callers that can end up with zero items own their own empty-state copy.
