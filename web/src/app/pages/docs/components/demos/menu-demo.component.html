Labels

No required/help-text/error-text inputs apply — a menu has no bound value to validate (see the narrative doc's "Deliberate omissions"). A section's own label is its group's accessible name only (aria-label, no visible heading text — see SPEC.md §6).

Keyboard contract

Arrow Up/Down move roving focus within a level, wrapping at the ends. Arrow Right/Enter/Space on "Export" above opens its submenu and focuses the first entry; Arrow Left or Escape closes it and returns focus to "Export". Home/End jump to the first/last enabled item. Type-ahead — focus the grouped menu and type a letter to jump to the next matching label.
