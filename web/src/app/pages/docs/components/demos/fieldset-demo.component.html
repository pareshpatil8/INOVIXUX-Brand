Variants/Structure — plain grouping vs. collapsible

Most fieldsets are pure grouping (collapsible="false", the default) — a plain <legend> with no interactive affordance. Setting collapsible renders the legend as a disclosure button (aria-expanded + aria-controls) that shows/hides the content region. Click the second legend to toggle it.

States

disabled sets the native <fieldset disabled> attribute, which cascades to every real descendant form control for free — both <ino-input>s below are inert without this component touching them. readonly only locks the collapse toggle (behavior-only, no aria-readonly — group role doesn't support it, SPEC.md §3); descendant fields are unaffected. loading dims the content and shows a spinner (aria-busy). invalid (via the error string) clears once both fields are filled, so the channel can be watched arriving and leaving.

Sizing — sm / md / lg (padding scale)

size only re-points --ino-control-padding-inline-roomy (doc 26 §5: "padding scales") — a fieldset has no single line-height control of its own, so it does not read the full height/font/icon/gap set a pressable control does. Content below each legend is identical; only the fieldset's own padding changes.

Density — dense vs. fluid

Density is a global [data-density] token axis, not a per-component @Input(). This docs page renders in the dense register; the right-hand pane overrides to fluid. --ino-control-padding-inline-roomy is re-declared under both [data-density] blocks, so density composes with size for free.

Labels — legend wrapping, RTL

legend is the component's one label — native <legend>, so screen readers announce it as the group's accessible name for every descendant control for free (no aria-labelledby wiring needed). The stylesheet uses logical properties only (padding-inline, margin-inline-start, border-inline-start-color), so it mirrors correctly under dir="rtl".

Keyboard contract

When collapsible, the legend is a native <button>: Tab reaches it as a normal stop (readonly instances stay reachable too — only a disabled fieldset's toggle leaves the tab order, since the native <fieldset disabled> cascade disables it the same as every other descendant control); Space or Enter toggles collapsed and emits collapsedChange (native button activation, no custom keydown handling). When not collapsible, the legend has no tab stop at all — Tab moves straight into the grouped fields in document order.
