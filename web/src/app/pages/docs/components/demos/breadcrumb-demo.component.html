Collapsed-middle overflow

maxVisible collapses a long trail to "first + … + last two" once items.length exceeds both maxVisible and a floor of 3. Activate the … button to open the popover listing the hidden middle crumbs — each is itself a real navigable link.

States

Default/hover/focus-visible/active are live on every navigable crumb above — tab onto one for the focus ring, or hover for the accent underline. Current-page is demonstrated by the last entry in every trail on this page. Disabled (per-item) renders inert text with aria-disabled, never navigable. Readonly (whole trail) applies the same inert-text treatment to every non-current crumb. Loading swaps in a skeleton trail with aria-busy="true" on the landmark. Empty renders nothing at all — no nav landmark — rather than a pointless empty one.

Sizing & density

"Sizing: one size" per the spec row — there is no size input or [data-size] axis. The component reads the bare unsuffixed --ino-control-* aliases directly, so density still composes for free without a sizing input to coordinate: this docs page runs in the dense register (left pane); the right pane overrides to fluid via [data-density="fluid"].

Labels — wrapping and RTL

No required/help-text/error-text inputs apply (a breadcrumb has no bound value to validate — see the narrative doc's "Deliberate omissions"). A long individual label wraps inside its own crumb rather than truncating or forcing the trail to overflow its container. The stylesheet uses logical properties only (margin-inline-end on the separator), so the trail mirrors correctly under dir="rtl".

Keyboard contract

Tab moves between navigable crumb links and the … overflow trigger — disabled/readonly crumbs are plain text and are never part of the tab order. Enter/Space activate a focused link or open/close the overflow trigger. Inside the opened popover, focus is trapped and Escape closes it, returning focus to the … trigger (the same [inoFocusTrap] contract <ino-popover> documents elsewhere).
