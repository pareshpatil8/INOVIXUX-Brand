Single-selection

Default single-selection listbox. Options are grouped ("Fruit" / "Vegetable") and one row ("Durian") is disabled. ArrowUp/ArrowDown move the roving tab stop and select the newly-focused row; Home/End jump to the first/last enabled row.

Multiple-selection (checkboxes)

[multiple]="true" renders a checkbox per row and toggles membership on click/Space/Enter instead of replacing the selection. ArrowUp/ArrowDown move focus only here — they do not change selection.

Filter — narrowed to zero results

The always-visible filter box narrows the list as you type. Below, the filter query "{{ filteredEmptyQuery }}" matches none of the options, producing the .ino-listbox--filtered-empty host class and the "No options match your filter." message. Clear the filter box (or press Escape) to see the full list again.

States

Default, disabled, readonly, invalid, and loading states below are static snapshots. Hover / focus-visible / active / selected are live on every enabled listbox on this page — hover or tab onto any row above to see them.

Keyboard interaction (APG Listbox pattern)

Focus any listbox above and try these keyboard shortcuts:

  • Tab / Shift+Tab: move focus onto/off the roving tab stop
  • Arrow Up/Down: move the roving tab stop (single-selection also selects; multi-selection moves focus only)
  • Home / End: jump to the first/last enabled row
  • Space / Enter: select (single) or toggle membership (multiple) of the focused row
  • Printable character: typeahead — jump to the next row whose label starts with the typed text
  • Arrow Down from the filter box: moves focus from the filter box into the list
  • Escape in the filter box: clears the filter query
