Overlay Positioning Regression (INO-364)

The popup used to anchor against whatever positioned ancestor happened to exist on the host page instead of its own trigger. These reproduce the two ancestor shapes that broke it — cycle the theme switcher above to confirm all three themes.

Positioned ancestor (appendTo="self", default) — the panel stays anchored under the trigger, not offset by the surrounding position: relative wrapper.

Scrolling/clipping ancestor, appendTo="self" — the overlay never leaves this ancestor's DOM subtree, so it can be clipped.

Same scrolling ancestor, appendTo="body" — the panel is reparented to document.body and escapes the clip.

Mobile Parity

Mobile disposition (SPEC.md §9): The time picker is deliberately not ported to React Native or Flutter. Native datepickers are scoped to single-date selection only (touch grid + prev/next month navigation). Rationale: no native spinner/AM-PM UI has been designed for either platform; adding one mid-port would be inventing a second, unaudited control. This keeps both native ports at the documented ~40% cost target. Time selection on mobile apps uses the platform's native time picker widgets instead.
