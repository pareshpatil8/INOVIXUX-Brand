Structure (anatomy)

One <svg viewBox="0 0 100 100"> holding five parts; the rendered diameter comes from the host's --ino-knob-dial custom property alone, so every part scales proportionally across the three dial sizes.

Part Element Notes
Range arc path.ino-knob__range Full 270° sweep, surface-sunken stroke; danger stroke when error is set
Value arc path.ino-knob__value min → current value, accent stroke; accent-active while hovered/dragging
Handle g.ino-knob__handle The focusable role="slider" element (one tab stop)
Indicator circle.ino-knob__indicator Dot at the value's angle on the arc
Value label text.ino-knob__text Centre, valueTemplate-formatted, aria-hidden (duplicates aria-valuetext)

Variants — value display and format

Variants — min / max / step

Drag anywhere on the dial (the pointer's angle maps to a value; the 90° bottom gap snaps to the nearer bound) or focus the dial and use ArrowUp/Right, ArrowDown/Left, PageUp/PageDown, Home and End. valueChange fires once per committed step change.

States

The "dragging" state (doc 26 §5 row) is interaction-driven — press and drag any editable dial to see the value arc and indicator switch to the active accent. "At min"/"at max" show the at-bounds indicator stroke; keyboard steps clamp at the bounds.

dense

The dial is not a text-entry control and has no dense-register height row — it renders identically in both densities (see SPEC.md §3).

Labels

The third dial has no visible label — its accessible name comes from the ariaLabel input (the §5 row's "value label + aria-label" cell).

<ino-label> sets no white-space/text-overflow, so a long label wraps onto multiple lines rather than truncating — shown here at size="sm", where horizontal space next to the dial is tightest.

RTL spot-check

The dial's geometry is deliberately unmirrored in RTL — clockwise-is-more has no directional locale convention (see the docs page's Accessibility contract).
