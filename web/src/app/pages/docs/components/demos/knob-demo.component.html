Variants — min / max / step

Drag anywhere on the dial (the pointer's angle maps to a value; the 90° bottom gap snaps to the nearer bound) or focus the dial and use ArrowUp/Right, ArrowDown/Left, PageUp/PageDown, Home and End. valueChange fires once per committed step change.

States

The "dragging" state (doc 26 §5 row) is interaction-driven — press and drag any editable dial to see the value arc and indicator switch to the active accent. "At min"/"at max" show the at-bounds indicator stroke; keyboard steps clamp at the bounds.

Labels

The third dial has no visible label — its accessible name comes from the ariaLabel input (the §5 row's "value label + aria-label" cell).

RTL spot-check

The dial's geometry is deliberately unmirrored in RTL — clockwise-is-more has no directional locale convention (see the docs page's Accessibility contract).
