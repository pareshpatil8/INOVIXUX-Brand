Variants — toolbar presets (basic / full)

basic carries inline styles (bold/italic/underline) and lists; full adds headings (H2/H3), a code block, link/unlink and clear formatting. Re-activating the current block format (e.g. H2 on an H2 line) reverts the line to a paragraph. Links prompt for a URL and reject anything that is not http(s): or mailto:.

States

Hover, focus-visible and the pressed format-toggle treatment are interaction-driven — tab into the toolbar (one tab stop, arrows rove) and the content area to see the focus rings; place the caret in bold text to see the toggle's aria-pressed state follow the selection. At-limit is a counter-only signal — it is not the invalid state.

Labels

A contenteditable region is not labelable by label[for], so the visible label is wired with aria-labelledby and clicking it still focuses the editor.

Sanitized paste + char limit

Paste is intercepted and rebuilt against an allowlist (p, br, strong, em, u, h2, h3, ul, ol, li, pre, code, a); b/i/h1/div normalize to strong/em/h2/p, every attribute is stripped except a protocol-checked href, and a paste that would overflow the budget is trimmed to plain text.
