Structure — basic selection

selectionMode="basic" (default), single selection. Click a row, or use Arrow keys to move the roving tab stop and Enter/Space to activate it. The always-visible filter box above the tree searches the whole loaded tree and auto-expands matching branches.

Structure — basic, multiple

[multiple]="true" toggles a row's membership without replacing other selections — plain row selection, not the checkbox cascade below.

Selected: {{ multipleValue.length ? multipleValue.join(', ') : '(none)' }}

Structure — checkbox selection, partial-checked

selectionMode="checkbox" always allows multiple selection. Checking a branch cascades to every loaded descendant; a branch with some but not all descendants checked renders aria-checked="mixed" (the "partial-checked" state, doc 26 §5).

Lazy loading

A node with hasChildren: true and no loaded children renders the expand affordance anyway. States — disabled, readonly, invalid, loading

[disabled]="true" removes every row from the focus order. [readonly]="true" keeps rows focusable but blocks activation. [error]="'...'" sets aria-invalid and renders an alert message. [loading]="true" is the component-level async flag — distinct from a per-node "loading branch" state (see the lazy-loading demo above).

Empty state

When [nodes]="[]", the tree shows "No options." in place of rows. Typing into the filter box with zero matches shows "No matches." instead — try it in any demo above.

Keyboard navigation

Follows the WAI-ARIA APG tree view pattern with roving tabindex:

  • Tab moves focus into/out of the tree (to the roving tab stop)
  • ArrowDown/ArrowUp move the roving tab stop to the next/previous enabled row
  • ArrowRight expands a collapsed branch, or moves into its first child if already expanded
  • ArrowLeft collapses an expanded branch, or moves to its parent
  • Home/End jump to the first/last visible row
  • Enter/Space activates the row (select/toggle/check depending on selectionMode)
