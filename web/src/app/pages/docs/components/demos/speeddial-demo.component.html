Directions — linear up / down / left / right

Directions are physical (a FAB anchors to a screen corner, not text flow); an RTL layout passes the mirrored direction at the call site. Horizontal dials show action labels below the buttons so labels never overlap neighbouring actions.

Circle & quarter-circle

type="circle" spreads actions on a full ring around the FAB; type="quarter-circle" uses a 90° arc opening into the quadrant named by direction. radius sets the ring distance in px.

Mask

[mask]="true" renders a full-viewport scrim behind the open dial (--ino-color-overlay-scrim). Clicking the scrim closes the dial.

Sizing — fab sm / md / lg × density

The FAB reuses the shared control-height scale as its diameter: sm 36px, md 44px (default), lg 52px. Action buttons stay one fixed 36px size on every FAB size. Diameters are fixed px, so the dense/fluid density register leaves the dial unchanged — the panes below prove it composes in both.

States — disabled dial

[disabled]="true" disables the FAB trigger itself: native disabled, muted fill, no shadow, never opens. (Open and disabled-action states are demonstrated in the live example above.)
