Service API — open(), onClose, config

<ino-dynamic-dialog> is mounted once below (a slot, same contract as <ino-toast-container>) and renders whatever InoDynamicDialogService.open() queues as an <ino-modal>. Each button opens DynamicDialogDemoContentComponent — a stand-in for any caller-supplied component — with a different config and awaits its onClose promise.

A11y — focus return

The dialog's focus trap captures document.activeElement the instant it mounts — whichever button above you clicked — and restores focus to that same button on close (Escape, backdrop click, Cancel, or Confirm). See the narrative doc's "Focus-return for the service flow" section for why no extra code is needed for this.
