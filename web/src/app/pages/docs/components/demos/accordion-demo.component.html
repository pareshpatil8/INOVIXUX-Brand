Variants — single-expand (default) vs multiple-expand

[multiple]="false" (default) enforces radio-like mutual exclusion: opening one tab closes all others. [multiple]="true" allows any number of tabs open simultaneously. Both modes follow the WAI-ARIA APG accordion pattern — the difference is only in close-others logic.

Icon position — start (default) vs end

[iconPosition]="start" (default) places the chevron before the text, reading as a visual bullet. [iconPosition]="end" places it after the text, reading as a disclosure hint. The parent accordion cascades this value to all tabs.

Nested accordions

An <ino-accordion> inside an <ino-accordion-tab>'s content. The inner accordion's tabs should have headingLevel one rank deeper than the outer accordion's tabs (caller responsibility, no automatic detection). Arrow keys do not cross accordion boundaries — each is a separate roving-tabindex group.

Sizing — compact vs comfortable

Two-value scale per the spec row (not sm/md/lg). size="compact" maps to --ino-control-padding-inline-roomy-sm; size="comfortable" (default) reads the bare alias. Keyboard navigation (APG accordion pattern)

Tab enters the accordion at the first tab header; once inside, roving tabindex keeps only the focused header tabbable. ArrowDown moves focus to the next tab (wraps); ArrowUp moves to the previous tab (wraps). Home jumps to the first tab; End jumps to the last tab. Enter/Space toggles the focused tab.
