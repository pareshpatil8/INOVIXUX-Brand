Variants / Structure — label, icon, avatar

Three content forms (doc 26 §5 "label+icon+avatar"): plain label, label with a projected [icon], and label with a projected [avatar] (here an <ino-avatar>). All static — no interaction, no remove button.

Static vs. interactive

A static chip (interactive="false", the default) renders a non-interactive <span> — same precedent as ino-tag. An interactive chip renders a real <button> and emits (chipClick). Click the interactive chip below — the count increments.

Interactive + pressable (filter-chip toggle)

pressable turns an interactive chip into a WAI-ARIA toggle button (aria-pressed), the same pattern ino-toggle-button uses. Click any chip below to toggle it independently — selected chips take the accent tint.

Removable (button-in-group)

removable="true" adds a trailing remove button, wrapped with the main content in a role="group" — the same button-in-group contract ino-inputtags' per-tag chips already use (a <button> cannot contain another <button>). Click the × to remove a chip, or focus a chip and press Delete/Backspace. Removal fades the chip out before it actually leaves the list — watch the transition.

Removable + interactive (two sibling buttons)

When both interactive and removable are set, the main button and the remove button render as siblings inside the same group — never nested.

States

Default, disabled, and readonly snapshots. Disabled dims and blocks all interaction; readonly dims less (the label is still meant to be read) and blocks removal but not focus.

Sizing

Three sizes: size="sm", size="default", and size="lg".

Keyboard interaction

Focus any removable or interactive chip above and try these keyboard shortcuts:

  • Tab: moves between the main chip and its remove button independently
  • Enter / Space: activates whichever button has focus
  • Delete / Backspace (main chip focused, removable): removes the chip
