States

Default/hover/focus-visible/active are live on every trigger/link above — tab onto one for the focus ring, or hover for the surface-sunken fill. Open-panel is the trigger's own aria-expanded state — click "Payments" above to see the chevron rotate and the panel appear. Active-item renders bold with aria-current="page" — see "Pricing" in the active-item pane below. Disabled on a top-level item removes it from Arrow-key navigation and its panel (if any) can never open. Readonly (whole menu) renders every leaf as inert text while panels still open/close. Loading swaps in skeleton bars with aria-busy="true". Empty renders the emptyLabel message rather than nothing.

Sizing & density

"Sizing: compact/comfortable" per the spec row applies to the bar only. comfortable (default) reads the unsuffixed --ino-control-* aliases; compact re-points to the -sm tier. Both compose with density — this docs page runs dense (left pane); the right pane overrides to fluid via [data-density="fluid"]. The open panel's own link rows always read the fixed overlay-compact scale regardless of this size — open "Payments" in both panes to compare.

Labels — menubar label, group headings, long-label wrapping

The spec row's "menubar label" is the ariaLabel input, naming the role="menubar" landmark for assistive tech — not a visible label. No required/help-text/error-text inputs apply (a mega menu has no bound value to validate — see the narrative doc's "Deliberate omissions"). A column's own heading is its visible group label. A long individual link label truncates with an ellipsis rather than forcing the row to overflow its column.

Keyboard contract

One tab stop on the bar itself (roving tabindex): ArrowRight/ ArrowLeft move between top-level items, wrapping; Home/ End jump to the first/last non-disabled item; ArrowDown, Enter, or Space opens the focused item's panel and focuses its first link. Inside an open panel: ArrowUp/ArrowDown move within a column, wrapping; ArrowRight/ArrowLeft move to the adjacent column, and at the panel's edge move to and open the adjacent top-level item's panel; Home/End jump within the current column; Escape closes the panel and returns focus to its trigger. orientation="vertical" swaps the bar's own axis (ArrowUp/ArrowDown move between items, ArrowRight opens a panel) — try it on the vertical pane above.
