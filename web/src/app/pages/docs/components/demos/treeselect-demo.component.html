Single-selection

Click to open the panel. Picking a row selects it and closes the panel, same as ino-select. ArrowRight/ArrowLeft expand/collapse a branch or move to its parent; ArrowUp/ArrowDown move the active row.

Multiple-selection (flat membership)

selectionMode="multiple" toggles membership without closing the panel and without cascading to a branch's descendants — picking "Engineering" alone would not also pick "Frontend"/"Backend".

Checkbox selection (cascading tri-state)

selectionMode="checkbox" cascades to every loaded descendant and re-derives each ancestor's checkbox. Below, "Web" and "API" are checked, so "Frontend", "Backend", and "Engineering" render the indeterminate ("mixed") state — not all of their children are checked, but at least one descendant is.

Lazy children (async loadChildren)

"Archived projects" has hasChildren: true with no children loaded yet. Expanding it emits (loadChildren); this demo answers by setting that node's loading: true (rendering the loading-branch spinner in place of the chevron) for 600ms, then pushes a new nodes array back in with its children populated — the same async-datasource contract ino-autocomplete's search output documents.

Filter — narrowed to zero results

The in-panel filter box narrows the tree as you type, auto-expanding every surviving branch. Below, the panel is already open and the filter query "{{ filteredEmptyQuery }}" matches none of the labels, producing the "No matches." empty state. Clear the filter box (or press Escape) to see the full tree again.

States

Default, disabled, readonly, invalid, and loading states below are static snapshots. Hover / focus-visible / active are live on every enabled trigger on this page — tab onto any trigger above to see them.

Sizing

size accepts sm / default / lg, same scale as every other Tier-1 form control.

Keyboard interaction

Focus any trigger above and try these keyboard shortcuts:

  • Enter / Space / ArrowDown (closed): open the panel
  • ArrowUp / ArrowDown (open): move the active row
  • ArrowRight: expand the active branch (or move into it if already expanded)
  • ArrowLeft: collapse the active branch (or move to its parent if already collapsed)
  • Home / End: jump to the first/last enabled row
  • Enter / Space (open): select (single) or toggle membership/checkbox of the active row
  • Escape: close the panel without committing
  • Tab: close the panel and move focus on
