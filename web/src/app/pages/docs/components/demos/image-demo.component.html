Mobile — React Native + Flutter ports

Per doc 26 §5 "Port both (base render; lightbox web-only)" — InoImage ships for React Native (mobile/react-native/src/components/InoImage.tsx) and Flutter (mobile/flutter/lib/widgets/ino_image.dart) with the same loading placeholder, error-fallback, caption, and intrinsic/fit sizing as web. The lightbox is web-only — neither mobile port has a focus-trap primitive of its own in this codebase.
