Keyboard contract

Right-click or Shift+F10 (browser default) opens the menu. Arrow Up/Down move the active row, clamped at the first/last enabled row. Home/End jump to the first/last enabled row. Arrow Right expands a submenu (if the current item has children). Arrow Left collapses an open submenu. Enter or Space activates the active row. Escape closes the menu (closes submenu first if one is open, then closes the menu). Focus returns to the trigger element on close.
