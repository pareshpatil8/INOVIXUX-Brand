Variants — connectors + expand/collapse subtrees

Default node rendering is label + sublabel; connectors are CSS borders (half-rails + drop stubs) in --ino-color-border, so they reflow with zoom, density and RTL. Branch cards carry a chevron toggler — subtrees start expanded, and collapsing hides the subtree and its connectors (aria-expanded tracks it). Keyboard: one tab stop; ArrowDown expands/descends, ArrowUp collapses/ascends, ArrowLeft/Right move between siblings, Home/End jump the row.

Node templates

{{ node.data }} {{ node.label }}

One projected ng-template renders inside every card with the node as context (let-node); node.data is an opaque bag the component never reads. The card chrome — selection, focus ring, connectors — stays with the component, so a custom template cannot break the a11y contract.

Selection (selectionMode="single")

Click or Enter/Space selects by node.value (currently {{ selected || 'none' }}); activating the selected node again clears the selection — a chart selection is a highlight, not a form commitment. The selected card pairs --ino-color-accent with --ino-color-accent-text-safe. The default selectionMode="none" renders no aria-selected at all.

States

Loading is chart-level — aria-busy, a spinner overlay, interaction suppressed (per-branch lazy loading is a deliberate omission). A disabled chart leaves the tab order entirely; a disabled node is skipped by traversal and selection but its subtree stays reachable. Hover and focus-visible are interaction-driven — tab in and traverse with arrows to see the roving focus ring.

Sizing — zoom scales (0.75 / 1 / 1.5)

zoom (clamped to 0.5–2) multiplies --ino-control-font-size on the chart surface and every internal length is in em — cards, text, gaps and connectors scale together with real layout reflow, not a blurry transform: scale(). Wide charts scroll inside the component's own scroller, never the page.

Density

dense

fluid

Density composes with zoom for free: dense re-points --ino-control-font-size, the base the zoom factor multiplies.

Labels — chart label

The chart label names the role="tree" via aria-labelledby; ariaLabel covers label-less instances. Long node labels wrap inside the card (max-inline-size: 14em) instead of stretching the chart.
