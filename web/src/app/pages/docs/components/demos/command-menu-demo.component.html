Sizing & density — fixed footprint

"Sizing: fixed" per the spec row — one max-inline-size: 640px footprint, no sm/default/lg axis. Rows still compose with density through the shared --ino-control-height/--ino-space-* tokens — the left pane's rows run dense, the right pane's run fluid.

Labels

label names the dialog landmark; searchLabel names the search combobox (the spec row's "search label"); placeholder and recentHeading are both overridable. No required/help-text/error-text inputs apply — a command menu has no bound value to validate (see the narrative doc's "Deliberate omissions").

Keyboard contract

⌘K/Ctrl+K toggles open/closed from anywhere in the document (the pane above with [hotkey]="false" is the one exception — it only opens via its button). Arrow Up/Down move the active row, clamped at the first/last enabled row. Home/End jump to the first/last enabled row. Enter activates the active row. Escape closes. Tab is deliberately unhandled — the search input is the only tabbable element inside the focus trap, so Tab wraps back to itself.
