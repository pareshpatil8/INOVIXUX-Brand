Default behavior (correct defaults)

Default component with separators=',' and addOnBlur=true. Type a tag and press Enter to add, or type a tag followed by comma to add, or type a tag and Tab/click away to add on blur. Press Backspace with empty input to remove the last tag.

Autocomplete suggestions

The suggestions list filters as you type. Use Arrow Up/Down to navigate, Enter to select, Escape to close, or click a suggestion to add it as a tag.

maxTags (at-max state)

With maxTags="3", once 3 tags are added, the input dims and becomes non-interactive. The dropdown never opens when at-max. Chips remain removable — remove one to add another.

validateTag (tag-invalid state)

The validateTag callback marks individual chips invalid. Below, tags that are all uppercase (and longer than 1 character) are rejected and styled with --ino-color-error. Try typing "INVALID" or "REJECTED" and pressing Enter.

States

Default, disabled, readonly, and invalid/error states below are static snapshots. Hover / focus-visible / active are live on every enabled inputtags on this page — hover or tab onto any field above to see them.

Sizing

Three sizes: size="sm", size="default", and size="lg". The generic renderer cannot produce this row (it requires a "primary" enum input alongside size), so this custom demo provides it explicitly.

Density — dense vs. fluid

This docs page renders in the dense register by default ([data-density="dense"] on the layout host); the pane on the right overrides to the fluid row-height floor to show the contrast.

Keyboard interaction

Focus any inputtags above and try these keyboard shortcuts:

  • Enter / comma (,): add the current input as a tag
  • Tab / click away (blur): add the current input as a tag
  • Backspace (empty input): remove the last tag
  • Arrow Up/Down: navigate suggestions
  • Enter (suggestion active): select the active suggestion
  • Escape: close the suggestions dropdown
  • Click a chip's × button: remove that tag
