Drill-down (structure)

Click the trigger (or press Enter / Space / ArrowDown) to open the panel at the root level. Rows with a › caret are parent options: activating one replaces the panel with its children and pushes it onto the breadcrumb bar — it never becomes the value (SPEC.md §2, leaf-only selection). Only a leaf commits a value and closes the panel. "Antarctica" is a root-level leaf, so it is selectable without drilling at all; "Canada" is a disabled parent and "Kerala" a disabled leaf — both skipped by ArrowUp/ArrowDown and by typeahead.

Selected value — full path on the trigger

With a leaf selected, the trigger shows the whole root-to-leaf breadcrumb (selectedLabel), not just the leaf's own label — so "Maharashtra" reads as "Asia / India / Maharashtra" and is unambiguous between trees that repeat a leaf name. Reopening always starts at root, but seeds the active row on the selection's root-level ancestor ("Asia") so a keyboard user does not have to re-scan the level.

Custom option template

A projected <ng-template #optionTemplate let-option> renders each row at any level, receiving the whole InoCascadeSelectOption — here a product name plus its SKU code. The caret, active/selected styling, and the leaf-only selection rule are unchanged; only the row's own content is yours.

open-level state — drilled in, breadcrumb showing

The panel below is already open and drilled one level in, which is the component's open-level state (.ino-cascade-select--level-open, SPEC.md §5): the breadcrumb bar and its ‹ back button only render below the root level, so this is the only way to see them in a screenshot. Click a breadcrumb item to jump back to that level, the back button (or ArrowLeft) to go up one. Clicking anywhere outside dismisses the panel — reopen it and press ArrowRight on "Asia" to get back to this state.

Empty tree

[options]="[]" with the panel open renders the "No options found." empty message rather than a zero-height panel — the same empty-state contract ino-select and ino-listbox publish. This panel is also pre-opened; click outside to dismiss it.

States

Default, disabled, readonly, invalid and loading below are static snapshots; disabled, readonly and loading all refuse to open at all. Hover / focus-visible / active are live on every enabled trigger on this page — tab onto any of them to see focus-visible, and hold the pointer down for active.

Labels — required marker, hint, error, placeholder

label/required/hint/error render through the shared ino-label leaf and the same hint/error paragraph pair as ino-select (SPEC.md §6). hint and error are mutually exclusive in the DOM — an error replaces the hint and becomes the trigger's aria-describedby target, with role="alert". With no selection the trigger shows placeholder, which is also what the panel's role="listbox" falls back to for its accessible name when no label is given.

Sizing

size accepts sm / default / lg (InoControlSize), the same three control-size rungs every other Tier-1 form control reads, applied to the trigger, the label and the panel's rows together.

Density — dense vs. fluid

Density is a global [data-density] token axis, not an @Input(). This docs page renders in the dense register by default; the pane on the right overrides to the fluid row-height floor to show the contrast at the same size.

Dense-table usage

In a dense table cell the control carries no label of its own — the column header already names the cell, and the trigger's own accessible name comes from the text it renders (the selected path, or the placeholder when empty). So each cell takes size="sm" and a placeholder instead of a stacked label block.

Keyboard interaction

DOM focus never leaves the trigger (role="combobox"); the active row is tracked logically through aria-activedescendant. Focus any trigger above and try:

  • Enter / Space / ArrowDown / ArrowUp (closed): open the panel at root
  • ArrowDown / ArrowUp (open): move the active row within the current level (clamped, no wrap)
  • ArrowRight: drill into the active row, if it has children
  • ArrowLeft: go back one level, if not at root
  • Home / End: jump to the first/last enabled row in the current level
  • Enter / Space (open): activate the active row — drill in (parent) or select + close (leaf)
  • Printable character: typeahead within the current level only (500 ms reset window)
  • Escape: close the panel entirely — it does not step back a level first
  • Tab: close without restoring focus to the trigger (focus is already moving on)
