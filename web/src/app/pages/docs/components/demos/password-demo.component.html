Default (showStrengthMeter=true)

Default component with showStrengthMeter=true (the component's documented default, not the generic renderer's forced false). Type a password to see the strength meter update live. The meter uses a fixed built-in heuristic (length ≥ 8, upper+lower case, a digit, a symbol, plus a length ≥ 12 bonus, capped at 4). Both the bar and label live inside an aria-live="polite" region so the label change is announced as you type.

Strength meter progression

Passwords typed in progressively showing the strength meter across its score range: Too weak (empty or very weak), Weak (1 point), Fair (2 points), Good (3 points), Strong (4 points). The meter is a single built-in heuristic, not a policy statement — the policy hint panel below is the customizable surface for actual requirements.

Policy hint panel (policyRules)

[policyRules]="INO_PASSWORD_DEFAULT_POLICY_RULES" shows the policy hint panel with a mix of met/unmet rows. Each row re-evaluates live and shows a met/unmet checkmark. Empty policyRules (default) hides the panel entirely. Pass INO_PASSWORD_DEFAULT_POLICY_RULES (length/case/digit/symbol) for a sane default, or author your own rules for a real product policy. This is deliberately a different signal from the strength meter — a password can satisfy every policy row while the meter still reads "Fair".

States

Default, disabled, readonly, required, and invalid/error states. Hover and focus-visible are live on every enabled password field on this page — hover or tab onto any field above to see them. The error state sets aria-invalid="true" and renders the error text as a role="alert" message, wired via aria-describedby.

Sizing

Three sizes: size="sm", size="default", and size="lg". Height / padding-inline / font-size from the Wave 0 control-size scale. The generic renderer cannot produce this row (size is a type-alias input, so design-system.manifest.json has "values": null for it), so this custom demo provides it explicitly.

Density — dense vs. fluid

This docs page renders in the dense register by default ([data-density="dense"] on the layout host); the pane on the right overrides to the fluid row-height floor to show the contrast. Density and --ino-row-min-height fall out for free from the control-size tokens, same as every other sized component.

Labels — hint, error, wrapping, RTL

Label association via <ino-label for>; hint text; error text with role="alert"; long labels wrap; the reveal toggle button uses only logical properties (inset-inline-end) so it mirrors correctly under dir="rtl".

Reveal toggle

A real <button type="button"> at the trailing edge of the control, toggling the underlying <input> between password/text. aria-label flips between "Show password"/"Hide password"; aria-pressed reflects the revealed state. Click the button or tab to it and press Enter/Space to toggle.

Caps Lock warning

Shown while the field has caps lock on during typing (keydown/keyup), cleared on blur. Renders as role="status" — announced once when it appears, not on every keystroke. Try enabling Caps Lock and typing in any field above to see the warning appear.

Keyboard contract

Standard text-field keyboard model: Tab/Shift+Tab moves focus between the field and the reveal toggle; Enter/Space activates the toggle while it has focus; native caret navigation while the field is focused and not readonly.
