Tree Structure — hierarchical data with expand/collapse

The treetable combines a tree's expand/collapse model with a table's column layout. The first column is frozen by default and contains the expand chevron. Click chevrons or press ArrowRight to expand, ArrowLeft to collapse. Implements WAI-ARIA role=treegrid with roving tabindex and 2D keyboard navigation.

Sortable Columns

Columns with [sortable]="true" render a clickable header. Click once for ascending, again for descending, again to clear sort. Sort events allow external sort control or server-side sorting.

Density — dense vs fluid row heights

[density]="dense" uses --ino-row-min-height for compact layouts. [density]="fluid" (default) uses --ino-control-height-default for comfortable spacing. Both modes maintain WCAG 2.2 AA touch target minimums.

States — disabled, readonly, invalid, loading

[disabled]="true" prevents all interaction. [readonly]="true" renders controls but blocks interaction. [invalid]="true" adds a danger border. [loading]="true" shows skeleton rows.

Empty State

When [data]="[]", the component shows the [emptyMessage] in place of rows. Customize with your own message for context-specific guidance.

Keyboard Navigation

Follows WAI-ARIA APG treegrid pattern with roving tabindex:

  • Tab moves focus into/out of the grid (to first/last focusable cell)
  • Arrow keys navigate between cells (2D grid navigation)
  • Home/End move to first/last cell in current row
  • Ctrl+Home/Ctrl+End move to first/last cell in entire grid
  • PageUp/PageDown move up/down by 10 rows
  • ArrowRight on tree column expands collapsed branch
  • ArrowLeft on tree column collapses expanded branch or moves to parent
  • Enter/Space on tree column toggles expansion
