Structure — label, count-up value, delta, risk rows

value animates via inoCountUp on mount; each row's status resolves to a token-bound RAG chip in this component's own SCSS — callers cannot pass an arbitrary color.

Structure — value-only, no delta or rows

delta and a non-empty rows array are both optional; the row list is *ngIf="rows.length"-gated so an empty array renders no list at all.
