Variants

Outline (default), filled, without spinner buttons. All variants support keyboard interaction (Up/Down arrows, PageUp/PageDown, Home/End).

Prefix & Suffix

Static text before/after the input — useful for units, currency symbols, or contextual labels.

Modes — Currency, Percent, Decimal

Formatting modes control display only — the stored value is always a plain number. Currency and percent use Intl.NumberFormat for locale-aware formatting.

States

Default, disabled, readonly, invalid, at-min, and at-max states below are static snapshots. Hover / focus-visible / active are live on every enabled control on this page — hover or tab onto any inputnumber above or below to see them. At-min/at-max disable the corresponding spinner button and add a host class for custom styling.

Sizing

The three-rung control-size scale — sm / default / lg. Each size re-points --ino-control-height, --ino-control-padding-inline, and --ino-control-font-size tokens.

Labels — with hint, error, and wrapping

Label association via <ino-label for>, hint text for guidance, error text with role="alert" and aria-describedby for screen reader announcement. Long labels wrap naturally.

Keyboard interaction (APG Spinbutton Pattern)

Focus any inputnumber above and try these keyboard shortcuts:

  • Up/Down arrows: increment/decrement by step (default 1)
  • PageUp/PageDown: increment/decrement by step × 10
  • Home: jump to min (if set)
  • End: jump to max (if set)

All examples above have min and max set to enable full keyboard contract verification (INO-517 fix — the generic renderer's null defaults were transformed to NaN, breaking every keyboard guard).
