KYB / VENDOR-4471 — LIVE TRACE REV. 01

One system, two densities

The same trace motif and token set power a high-density risk dashboard for underwriters and a low-friction consumer surface — no separate design language to maintain.

Surface cards

One <ino-card> shell, three surface roles — the generic container every bento tile, KYB finding card, and mobile list row is built from.

Default surface

Standard raised card for page/section content — dashboard widgets, bento-grid tiles, mobile app list cards. Hover/focus to see the elevation state (respects prefers-reduced-motion).
Sunken surface

Inset panel — a card nested inside another card, or a code/data block that should read as recessed, not raised.
Overlay surface

Modal / bottom-sheet / popover body — paired with the --ino-color-overlay-scrim backdrop token, at elevation-2 so it reads clearly above page content.

Not a live modal — shown in-flow for the style guide.

Deployment tiers

Structural placeholder only — no commercial terms exist yet (INO-14 hold). Shown to prove the component pattern, not to price anything.
