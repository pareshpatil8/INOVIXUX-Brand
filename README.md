# INOVIXUX Brand

Brand architecture and identity system for INOVIXUX — DPI-aligned (India Stack / UPI / ABDM)
infrastructure spanning KYB underwriting, risk verification, and eventually healthcare/central
banking/AI use cases.

## Contents

- [`docs/brand/00-understanding-and-plan.md`](docs/brand/00-understanding-and-plan.md) —
  scope, timeline, implementation plan, and design-system onboarding notes.
- [`docs/brand/01-brand-architecture-concepts.md`](docs/brand/01-brand-architecture-concepts.md) —
  the three structural brand concepts awaiting human sign-off (INO-31).

Tech rails: Java / Spring Boot backend, Angular frontend. All design tokens are scoped to land
as Angular-consumable CSS custom properties. No tokens, CSS, or final assets are compiled until
a concept direction above is explicitly approved.
